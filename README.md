# Mini Library Management System (Python)

## Overview
A compact object-oriented implementation of a library system supporting:
Add / Search / Update / Delete books and members
Borrow / Return logic with constraints
Simple demo and tests

## Files
operations.py — core implementation (Library, Book, Member)
demo.py — demonstration script
tests.py — assertion-based tests
DesignRationale.md — design rationale (1–2 pages)
UML diagram — included in submission (hand-drawn or as UML.png/pdf)

## Requirements
Python 3.8+
No external dependencies

## How to run
1. Run demo:
   bash
   python demo.py
